隐私政策

最近更新：2026年4月27日 · 适用范围：本网站（realman-robot.com）
睿尔曼智能科技（北京）有限公司（以下简称"我们"）尊重并保护所有访问本网站用户的个人信息。本政策说明我们收集、使用、存储和保护您个人信息的方式，请您仔细阅读并理解。当您通过本网站表单向我们提交信息或继续使用本网站时，即视为您同意本政策的内容。

1. 我们收集哪些信息

本网站仅在您主动通过"联系我们"表单提交联系请求时收集以下信息：

信息类别具体字段是否必填
身份与联系方式姓名、工作邮箱必填
所属单位公司名称必填
地区所在地区（中国/海外）、省/自治区/直辖市 或 海外区域必填
咨询信息咨询类型（合作/销售/技术支持/媒体/招聘/其他）、详细需求描述咨询类型必填，详细需求选填
技术信息提交时间、IP 地址、来源页面、User-Agent系统自动记录，用于安全审计与防滥用

除上述信息外，本网站不会通过 Cookie、像素或第三方代码主动收集您的浏览行为或设备指纹用于商业广告。本网站仅使用浏览器 LocalStorage 记录您上次提交表单的时间戳（用于客户端防刷），该数据仅保存在您本地浏览器中，不会上传。

2. 我们如何使用这些信息

  • 由对应业务部门（销售、市场、技术支持等）联系并响应您的咨询；
  • 识别滥用行为（如机器人刷表单、注入攻击）并采取必要的防护措施；
  • 形成业务统计与售前线索台账，用于内部业务管理；
  • 在法律法规要求或监管部门合法请求下进行配合。

我们不会将您的个人信息用于上述以外的目的，不会出售或非法提供给任何第三方。

3. 信息的存储与跨境传输

表单数据存储于以下基础设施：

  • 静态站点：托管于 Vercel（CDN 节点遍布全球）；
  • 表单后端与数据库：Supabase（基于 AWS，主区域为 ap-southeast-1 / 新加坡）；
  • 人机验证：Cloudflare Turnstile。

这意味着您提交的表单数据可能跨境存储于上述云服务商的数据中心。我们已要求基础设施提供方满足合理的数据保护与安全措施（TLS 加密传输、静态加密存储、访问控制）。如您是中国大陆用户并对跨境存储有疑虑，请通过以下邮箱联系我们要求境内存储或删除。

4. 信息的保护措施

  • 传输加密：全站强制 HTTPS（HSTS preload），表单提交全程 TLS 1.2+；
  • 后端校验：所有提交均经过 Cloudflare Turnstile 人机验证 + 后端 Edge Function 严格的字段长度/格式/白名单校验，并对 HTML 标签进行剥离与危险字符正则拦截；
  • 访问控制：数据库启用 Row-Level Security（RLS），仅授权账户可读取联系表单数据；
  • 速率限制：单 IP 每分钟最多提交 5 次，单邮箱每天最多提交 3 次，超过即被拦截；
  • 安全响应头：CSP / HSTS / X-Frame-Options / X-Content-Type-Options 等 8 项响应头已配置；
  • 自托管脚本完整性：所有自托管 JS 资源使用 SRI（Subresource Integrity）校验防篡改；
  • 定期审计：本网站已先后接受信息化部多轮安全审计并完成整改。

5. 信息的保留期限

表单数据默认保留 24 个月，用于业务沟通与客户回访。超期数据每季度做一次清理。您也可以随时通过下方邮箱要求我们提前删除。
